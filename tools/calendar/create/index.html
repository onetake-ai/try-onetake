Create a calendar page link

Paste the share link of a Proton calendar. You get a link to a page where anyone can see the upcoming dates and add them to their own calendar, in one click.

Where do I find the Proton share link?
  1. Open calendar.proton.me in your web browser (sharing isn't possible from the Proton mobile apps).
  2. Click Settings (⚙️), All settings, Calendars, then select the calendar you want to share. Shortcut: click the settings icon next to the calendar in the left column.
  3. Scroll to Share with anyone and click Create link.
  4. Choose Full view. With "Limited view", people only see when you're busy, without the event names or the links to join.
  5. Click Copy link, and paste it below.

The link starts with https://calendar.proton.me/api/calendar/v1/url/.

One link per group: Proton allows up to 5 links per calendar. Create one for each group of clients and name it (Actions, Edit label). To stop sharing with one group, delete its link (Actions, Delete link): the other groups keep theirs.

A client's calendar stopped updating? Some calendar apps stop refreshing Proton links after a while. Create a new link here, send the new page link, and ask them to remove the old calendar and subscribe again.
